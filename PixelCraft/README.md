**🌟 Static Version - Optimized for GitHub Pages deployment!**

## 📋 Project Overview

PixelCraft is a comprehensive digital agency website that showcases modern web development practices, interactive features, and responsive design. This project demonstrates advanced front-end development skills and meets all the specified criteria for a professional web presence.

## ✨ Key Features

### 🎯 **Interactive Features (15+ Features)**

1. **Animated Particle System** - Dynamic background particles with mouse interaction
2. **Theme Switcher** - Dark/Light mode toggle with localStorage persistence
3. **Typewriter Effect** - Animated text on hero section
4. **Smooth Scroll Navigation** - Animated scrolling to sections
5. **Interactive Portfolio Filter** - Filter projects by category with animations
6. **Portfolio Lightbox** - Full-screen image viewer with navigation controls
7. **Testimonials Slider** - Auto-rotating testimonials with manual controls
8. **Modal System** - Quote requests and demo videos
9. **Newsletter Subscription** - Form with validation and success feedback
10. **Form Validation** - Real-time validation with user feedback
11. **Statistics Counter** - Animated counters on scroll
12. **Mobile Menu** - Responsive hamburger navigation
13. **Back to Top Button** - Smooth scroll to top functionality
14. **Parallax Effect** - Subtle parallax scrolling on hero section
15. **Enhanced Hover Effects** - Glow effects and animations on interactive elements
16. **Keyboard Navigation** - Arrow keys and escape for lightbox controls

## 🚀 How to Run

### Method 1: Direct File Opening

1. Download or clone the repository
2. Open `index.html` in your web browser
3. Navigate through the pages using the navigation menu

### Method 2: Live Server (Recommended)

1. Install a live server extension in your code editor
2. Right-click on `index.html` and select "Open with Live Server"
3. The website will open in your browser with hot reload

### Method 3: Local HTTP Server

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .

# Then visit http://localhost:8000
```
